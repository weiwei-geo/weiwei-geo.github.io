# Jekyll Website

Personal blog built with Jekyll.

## Development

```bash
bundle exec jekyll serve   # Start local dev server
```

## Structure

- `_layouts/` - HTML templates (default, post, posts list)
- `_includes/` - Reusable partials
- `_sass/` - SCSS partials (if using SCSS)
- `assets/css/` - Compiled CSS
- `_posts/` - Blog posts (YYYY-MM-DD-title.md format)
