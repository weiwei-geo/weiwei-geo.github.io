# Blog Posts

Place your blog posts here in this directory.

## Naming Convention

Files must follow the format: `YYYY-MM-DD-slug-title.md`

Example: `2026-04-15-hello-world.md`

## Required Front Matter

```yaml
---
layout: post
title: "Your Post Title"
date: 2026-04-15 12:00:00 +0800
tags: [tag1, tag2]
---
```

## Optional Front Matter

- `author` - Override default author
- `description` - Post description/subtitle
- `tags` - Categories/tags for the post
